Layout components arrange other views. Most screens are built from [VStack](vstack/) and [HStack](hstack/);
use a [Grid](grid/) for rows and columns, a [Box](box/) for overlapping content and a [ScrollView](scroll_view/)
for content larger than its frame. Sizes are set with a [Frame](frame/), positions with an
[Alignment](alignment/) or a [Position](position/).

For responsive layouts see [Stack](stack/), [View That Matches](../utility/view_that_matches/) and the
navigation splits [TwoColumn](twocolumn/) and [ThreeColumn](threecolumn/).

For interaction, a [Hover Group](hover_group/) swaps its content while the pointer is over it, and a
[Drag and Drop Area](dnd/) lets the user drag views onto each other.

Styling values like [Padding](../utility/padding/), [Border](../utility/border/) and
[Length](../utility/length/) are described under [Utility](../utility/).
