# Nago tutorials

Each directory is a runnable tutorial. Run one from a checkout of this repository

```bash
go run ./example/cmd/tutorial-01-helloworld
```

or without a checkout

```bash
go run go.wdy.de/nago/example/cmd/tutorial-01-helloworld@latest
```

and open http://localhost:3000.

The tutorials are documented with screenshots on [nago.dev](https://www.nago.dev/docs/examples/). The pages
include the sources from here, so a change of a tutorial shows up in the docs automatically. When you add,
rename or remove a tutorial, add or update its page as described in
[docs/MAINTAINING.md](../../docs/MAINTAINING.md).
